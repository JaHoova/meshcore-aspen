# RAK4631 + RAK13800 Ethernet TCP KISS Modem

Minimal Ethernet TCP KISS TNC firmware (`rak4631_rak13800_tcp_kiss`) for a RAK4631 (nRF52840 + SX1262) on a RAK19007 base board with a RAK13800 W5100S PoE/Ethernet module.

## What the Firmware Runs

- **TCP port `8001` (KISS TNC):** Single-client MeshCore KISS bridge (`FEND=0xC0`, `FESC=0xDB`, `SetHardware 0x06`, `TxDone 0xF8`, `RxMeta 0xF9`). A new connection closes the previous client immediately; idle sockets are reclaimed after `300` seconds.
- **TCP port `8002` (OTA control):** Accepts `START_OTA\n` and reboots into the Nordic BLE DFU bootloader (`NRF_POWER->GPREGRET = 0xB1`). KISS `SetHardware (0x06)` sub-command `0xFE` on port `8001` triggers the same reboot.
- **Ethernet & DHCP:** Derives a locally administered unicast MAC from `NRF_FICR->DEVICEADDR`, requests DHCP with bounded timeouts, renews leases via `Ethernet.maintain()`, and resets the W5100S (`WB_IO3`) automatically on link bounce or SPI loss. Optional static IP fallback is enabled with `-DETHERNET_STATIC_IP="192,168,1,50"` (and optional `_GATEWAY`, `_SUBNET`, `_DNS`).
- **Watchdog & Serial:** 60-second `NRF_WDT` (`RR[0]`) fed while both SX1262 and W5100S SPI buses respond, plus `115200` baud USB serial boot and connection logs.
- **SPI Mapping:** SX1262 uses `NRF_SPIM3` (`loraSpi`: MISO `45`, SCK `43`, MOSI `44`, NSS `42`, DIO1 `47`, RESET `38`, BUSY `46`); W5100S uses `NRF_SPIM2` (`ethSpi`: MISO `29`, SCK `3`, MOSI `30`, CS `26`).

## Build After `make prepare`

`firmware/nrf52840/.build/` is gitignored and regenerated by `make -C firmware/nrf52840 prepare`. Stage these tracked files into the upstream build tree and compile:

```bash
make -C firmware/nrf52840 prepare

mkdir -p firmware/nrf52840/.build/upstream/examples/rak4631_rak13800_tcp_kiss
cp firmware/nrf52840/tcp_kiss/{MinimalRak4631Board.h,TcpKissModem.h,TcpKissModem.cpp,main.cpp,auto_uf2.py} \
  firmware/nrf52840/.build/upstream/examples/rak4631_rak13800_tcp_kiss/

cat firmware/nrf52840/tcp_kiss/platformio_tcp_kiss.ini \
  >> firmware/nrf52840/.build/upstream/platformio.ini

pio run -d firmware/nrf52840/.build/upstream -e rak4631_rak13800_tcp_kiss
```

Optional static IP fallback build:

```bash
PLATFORMIO_BUILD_FLAGS='-DETHERNET_STATIC_IP="192,168,1,50"' \
  pio run -d firmware/nrf52840/.build/upstream -e rak4631_rak13800_tcp_kiss
```

## Outputs and Flashing

The build targets the S140 6.1.1 application offset (`0x00026000`) and writes both packages under `firmware/nrf52840/.build/upstream/.pio/build/rak4631_rak13800_tcp_kiss/`:

- **`firmware.uf2`:** Drag-and-drop onto the USB UF2 bootloader drive. Verify bytes `12–15` equal `00 60 02 00` (`0x00026000`) before flashing:
  ```bash
  xxd -l 32 firmware/nrf52840/.build/upstream/.pio/build/rak4631_rak13800_tcp_kiss/firmware.uf2
  ```
- **`firmware.zip`:** Application-only Legacy DFU package (`--dev-type 0x0052`, `--sd-req 0x00B6`) for BLE OTA DFU (`4631_DFU`).

## Triggering Remote BLE OTA DFU

```bash
# Port 8002 ASCII control listener
printf 'START_OTA\n' | nc <NODE_IP> 8002

# Port 8001 KISS SetHardware sub-command 0xFE
printf '\xc0\x06\xfe\xc0' | nc <NODE_IP> 8001
```
